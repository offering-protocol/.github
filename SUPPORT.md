# Support

## Questions and protocol design

Use [ODP Discussions](https://github.com/offering-protocol/odp-specs/discussions) for usage questions, protocol-design discussions, and questions that span multiple implementations.

## Defects and feature proposals

Open an issue in the repository that owns the affected specification or SDK. Include a minimal reproduction, the affected version, and the expected behavior. Protocol and wire-format proposals belong in [`odp-specs`](https://github.com/offering-protocol/odp-specs/issues).

## Security vulnerabilities

Do not open a public issue. Follow the `SECURITY.md` instructions in the affected repository.
