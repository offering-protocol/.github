# Offering Discovery Protocol

The Offering Discovery Protocol (ODP) is an open protocol for discovering, navigating, and inspecting offerings
published by services.

ODP is being designed to support small static catalogs through large marketplaces while allowing services to describe
their own structured offering data. It composes with enrollment, authentication, and payment protocols without
defining those workflows itself.

## Repositories

- [`odp-specs`](https://github.com/offering-protocol/odp-specs) — specifications, schemas, examples, test vectors, and
  conformance artifacts.
- [`odp-node`](https://github.com/offering-protocol/odp-node) — Node.js reference implementation.
- [`odp-go`](https://github.com/offering-protocol/odp-go) — Go implementation.
- [`odp-java`](https://github.com/offering-protocol/odp-java) — Java implementation.
- [`odp-python`](https://github.com/offering-protocol/odp-python) — Python implementation.
- [`odp-rust`](https://github.com/offering-protocol/odp-rust) — Rust implementation.

The project is in its initial design stage. Protocol discussions belong in
[`odp-specs` Discussions](https://github.com/offering-protocol/odp-specs/discussions).

Project website: [offeringprotocol.org](https://www.offeringprotocol.org)
